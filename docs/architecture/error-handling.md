# 에러 코드와 화면

회원 화면의 예약 · 취소 요청이 실패했을 때의 처리. **분기의 근거는 응답의 `code` 문자열 하나다.** HTTP 상태나 메시지 문구로 분기하지 않는다.

근거: PRD-0003 AC 3.1, PRD-0003 AC 3.2

| HTTP | code | 처리 | 변형 |
|---|---|---|---|
| 409 | `SEAT_TAKEN` | 시트 내용을 "방금 자리가 찼어요."로 교체하고 `home` 재조회 | `M-02/자리 참` |
| 409 | `ALREADY_BOOKED` | 오류 표시 없이 시트를 닫고 `home` 재조회. 정상 종료로 본다 | — |
| 422 | `NO_REMAINING` | 시트를 닫고 `home` 재조회. 줄에 사유 + 비활성 | `M-01/수업 줄/잔여 없음` |
| 422 | `CLASS_STARTED` | 시트 내용을 "이미 시작된 수업이에요" + `확인`으로 교체하고 `home` 재조회 | `M-02/시작됨` |
| 410 | `LINK_REVOKED` | 링크 무효 안내로 이동 | `M-04/기본` |
| — | 타임아웃 · 네트워크 | 재시도하지 않는다. "처리 결과를 확인하고 있어요" 표시 후 `home` 재조회로 성공 / 미처리를 판정 | `M-02/결과 확인 중` |

- 실패는 새 시트를 띄우지 않고 같은 시트 안에서 내용을 교체한다
- mutation 자동 재시도는 0회다. 타임아웃은 실패가 아니라 "모름"이다
